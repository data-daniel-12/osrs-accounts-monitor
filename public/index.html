🔌 API Endpoints for your Backend

You can make GET or POST requests from your backend in Python, Node.js, PHP, or any programming language:

GET /api/availability?format=simple&only_in_stock=true

Returns directly the lightweight map with sheet row numbers and their available quantity:

{
  "7": 1,
  "8": 8,
  "9": 10,
  "10": 11,
  "18": 6
}
GET /api/availability?format=pairs

Returns an array of pairs [[row, quantity], ...]:

[[7, 1], [8, 8], [9, 10], [10, 11]]
GET /api/accounts

Returns the complete accounts database with static columns (build, supplies, price) and live stock.

GET /api/stream

Server-Sent Events (SSE) connection to receive real-time push events whenever stock changes without polling.
